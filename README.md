**PikViewer** is a lightweight Windows image viewer designed to provide a clean and simple viewing experience without unnecessary UI elements. 
The project was created entirely using AI(Claude+ChatGPT), as an alternative to existing HDR image viewers while keeping the interface minimal, responsive and practical for everyday use.






Why i did this? 
- First of all because i tested a lot of image viewer, and none of them are for my taste. For me they looks really ugly, heavy interface and not practicall at all
  The only one that fits with me, which is the included with windows its broken due the second reason
- And that is because I use [dwm_eotf_rs](https://github.com/SERGEYDJUM/dwm_eotf_rs) with an strong gamma change to remove Windows washed out look that is produced due to wrong sRGB gamma,
